# Отмена записи по секретной ссылке сохраняет запись

У гостя нет аккаунта, поэтому право отменить конкретную запись даёт владение непредсказуемым кодом из секретной ссылки, полученной при создании записи. Код остаётся во фрагменте ссылки и передаётся API отдельно от URL; открытый раздел владельца не раскрывает ни код, ни ссылку.

Открытие ссылки только показывает детали: гостю нужно явно подтвердить отмену до начала звонка. Вместо удаления запись необратимо получает статус «отменена», чтобы владелец видел результат в списке предстоящих записей; её интервал при этом больше не занимает слоты ни одного типа встречи.
